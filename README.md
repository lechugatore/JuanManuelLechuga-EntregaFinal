# Rockeria Talento Tech

Sitio web llevando al rock arriba, desarrollado con HTML5 y CSS. Incluye página de inicio, tienda, contacto y carro de compras.

## Estructura

JuanManuelLechuga-EntregaFinal/
└── css/
└── img/
└── script/
├── index.html
├── styles.css
├── contacto.html
├── tienda.html
├── carrito.html

## Features

- Sitio con varias páginas HTML, con estructura semántica y navegación entre ellas
- Estilos propios en CSS, en archivos separados del HTML
- Diseño adaptable a distintos tamaños de pantalla (Flexbox o Grid, media queries)
- Contenido generado dinámicamente con JavaScript a partir de un arreglo de objetos
- Interacción con el DOM mediante eventos
- Uso de localStorage o sessionStorage para guardar datos
- JavaScript organizado en archivos separados
- Repositorio en GitHub con un README
